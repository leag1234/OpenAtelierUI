# OpenAtelierUI

OpenAtelierUI is an open-source AI interface developed under BSD-3-Clause, with compatibility for existing integrations and plugins as a core objective.

The project starts from the BSD-licensed Open WebUI v0.6.5 source at commit `07d8460126a686de9a99e2662d06106e22c3f6b6`. Original copyright and license notices are retained. New compatibility, migration, security and resource-use improvements are developed separately; newer upstream implementation is not an authorized development template.

Development is in progress. This repository is not a declaration of production readiness, complete compatibility or completed independent provenance review. Validation distinguishes working behavior from unsupported cases and preserves original data on migration copies.
