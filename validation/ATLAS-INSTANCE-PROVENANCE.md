# Atlas candidate instance lifecycle helper

`atlas_instance.py` is an operator-invoked, standard-library prototype for one isolated local instance. Its source-only command shape is:

```text
python3 validation/atlas_instance.py start --image openatelier-atlas-candidate:local --expected-image-id sha256:<64-lowercase-hex> --source-data /path/to/closed-copy/data --env-file /path/to/operator.env --workspace /path/to/new-private-workspace --network atlas-private --host-port 18080 --container-port 8080
python3 validation/atlas_instance.py status --workspace /path/to/new-private-workspace
python3 validation/atlas_instance.py stop --workspace /path/to/new-private-workspace
python3 validation/atlas_instance.py restart --workspace /path/to/new-private-workspace
```

The selected local image tag must resolve to the supplied image config ID. Docker commands use the verified image ID and `--pull=never`; the helper does not build, pull, or change networks. A named runtime network is required when publishing the explicitly selected port; `--network none` is refused because it cannot provide the requested loopback health/API endpoint. The operator owns network creation and any egress policy; this helper does not qualify the named network's isolation.

`start` refuses an existing workspace, a source directory containing symlinks or SQLite sidecars, a non-regular/missing `webui.db`, inputs over the copy limit, an unpinned/mismatched image, and an invalid env-file path. It records a deterministic tree hash/count/byte summary before copying and rechecks source and copied data before modifying the isolated copy. The explicit env-file path is retained in the mode-0600 manifest, but the file contents are never read or printed. The prepared mode-0600 manifest is inside a mode-0700 workspace and records the image/config ID, container identity labels, bind paths and input summaries.

The helper obtains `/app/backend/open_webui/static` and `/app/build/static` from a temporary, never-started container made from the pinned image; it merges the base static tree first and frontend static tree second into the fresh workspace static bind. It retains the original data DB under `pre-session/`, calls the packaged `session_epochs.py prepare-copy` against that retained DB, and replaces only the new data copy's `webui.db` with the prepared output. It enables the measured session, private-notes, imported-profile/history and lazy-local-embedding flags, and disables signup, title/tag/autocomplete generation and model auto-update. Other provider and trusted-header values remain supplied by the operator env file.

The app container is started non-root (`1000:1000`), read-only root, all capabilities dropped, no-new-privileges, 256 pids, 2 CPUs, 2 GiB memory, 64 MiB noexec/nosuid `/tmp`, and only explicit data/static writable binds. It publishes only to `127.0.0.1`. Startup health is bounded to 240 seconds by default. On an observed startup failure, it attempts a normal stop only after verifying its random instance label, pinned image ID and workspace bind paths; prepared copies and safe diagnostic state remain. `status`, `stop` and `restart` reread the private manifest and verify the same identity and mounts before touching the exact container. The copied candidate exposes no separate follow-up-generation or version-update toggle; the helper disables the measured title/tag/autocomplete and model auto-update controls without claiming those absent settings.

`test_atlas_instance.py` mocks Docker subprocesses and loopback health only. It exercises image pin mismatch, closed-source sidecar and symlink refusal, exact source/pre-session preservation, static merge precedence, session-copy invocation, startup flags/resources, manifest permissions/secrecy, lifecycle operations and refusal to stop a container with a mismatched owner label. It does not invoke Docker, start a container or make network requests. The primary owns real image/lifecycle integration, resource admission, HTTP journeys, restart/recovery and any operator-facing usability review. This prototype does not establish that Docker Desktop/Engine bind-mount ownership works on a target host, that the named network is private, or that a container has no egress.
