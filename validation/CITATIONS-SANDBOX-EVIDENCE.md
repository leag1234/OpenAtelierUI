# Citations modal passive HTML preview

The citations modal in `src/lib/components/chat/Messages/CitationsModal.svelte` passed citation HTML through `srcdoc` with sandbox privileges `allow-scripts allow-forms allow-same-origin`. This bounded old-BSD change sets the same iframe to `sandbox=""`, removing those opt-ins and applying the browser's default sandbox restrictions. It leaves `srcdoc={document.document}` unchanged, preserves the source link/open-file control and title, and leaves non-HTML citation content on the existing `<pre>` path.

The HTML branch now labels the content as a static preview and states that scripts and forms are disabled. After the primary's compiled candidate review found the original `text-xs text-gray-500 dark:text-gray-400` notice rendered as low-contrast RGB(155,155,155) on white, its style is now `text-sm text-gray-700 dark:text-gray-200`. These tokens resolve in the old Tailwind palette to #4e4e4e and #e3e3e3; the modal uses white and gray-900 backgrounds. The close icon button now has the accessible name `Close citation`; its existing click action remains `show = false`. Ordinary text and source selection remain available; interactive HTML behaviors that depend on scripts/forms or same-origin access are intentionally unavailable. The existing close control, source display, and direct open-original-file route remain in the source. No source bytes are rewritten.

The primary's compiled `a46f2e3` review found that the iframe's transparent canvas exposed unstyled black source text against the dark modal in dark mode, and that opening the citation left focus on the underlying message toolbar. The correction gives only the iframe a white background and `color-scheme: light`; it does not rewrite `srcdoc` or custom source styling. Only CitationsModal opts into common Modal's new focus support, with a named dialog, initial focus on the close control, inert body siblings, bounded Tab wrapping/focus escape recovery, and restoration to the opener when closed. Other Modal call sites retain the default `trapFocus=false` behavior.

`python3 validation/test_citations_modal_sandbox.py` runs seven named stdlib source checks for the empty sandbox and unchanged srcdoc expression, readable notice palette, accessible close name/action, light canvas, citation-only dialog/focus opt-in, source/open-file control, and non-HTML path. `node validation/modal_focus_lifecycle.cjs` deterministically evaluates the helper against a small fake DOM and checks 14 lifecycle assertions: initial focus, inert application/restoration (including a pre-existing inert sibling), forward/reverse Tab wrapping, focus escape recovery, listener cleanup, and opener restoration. This fake-DOM test is not a browser or compiled Svelte test. The primary owns a fresh compiled candidate browser review for both themes, Tab/Escape/direct-close, original-file control and exact iframe sandbox behavior. No corrected-candidate browser result is claimed here. Parent-document keydown cannot observe events originating inside a sandboxed iframe document; sibling inertness and focus recovery are intended to keep keyboard focus within the citation surface, but iframe-internal traversal remains unqualified pending the browser check.

This only changes the citations modal. The separate `Artifacts.svelte` configurable `allow-same-origin` behavior remains outside this lot. No interactive-artifact changes, frontend build, comprehensive XSS remediation, or production security claim is made.
