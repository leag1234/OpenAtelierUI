# Explicit async model compatibility spike provenance

This is a default-off adapter for a later fresh-volume evaluation. It changes no HTTP route, database model, configuration default, auth behavior, or dependency. It does not establish Atlas compatibility or product readiness.

`run_verified_bootstrap(script_path, expected_sha256, args=())` is the explicit launcher entry point in `open_webui.utils.async_model_bootstrap`; it is also available as `python -m open_webui.utils.async_model_bootstrap SCRIPT SHA256 [ARGS...]`. The helper accepts only a regular non-symlink file whose bytes fit within 1 MiB and match the supplied SHA-256. Nonblocking open prevents a FIFO from hanging before file-type refusal. The exact bytes read and hashed are sent over stdin to a new child process; later path changes cannot replace those bytes. Arguments are separate argv strings, no shell is used, and stdout/stderr are discarded. The child imports the existing application config before executing the selected script, temporarily proxies only the six named Functions/Models calls with `asyncio.to_thread`, and restores the original module bindings on normal return or exception. Nonzero child status is returned without script output or exception text; `SystemExit()` maps to success. This is an explicit script execution feature, not a sandbox; the operator-selected script runs with the child process's ordinary application privileges.

`adapt_filter_module` extends the existing task-local Filter SDK bridge. The historical direct Users bridge is unchanged. New Files/Chats adaptation is opt-in by authoritative function ID through `OPENATELIER_ASYNC_FILTER_MODEL_IDS`, a JSON array that defaults to unset/empty. Only module-level direct/aliased `Files` or `Chats` bindings and exact module-level `importlib` / `import_module` bindings are adapted for selected IDs. Selected exact imports of `open_webui.models.files` and `open_webui.models.chats` receive a local module view for `Files.get_file_by_id` or `Chats.get_chat_by_id_and_user_id`. Unselected filters retain native synchronous values, including `None` inside async handlers. The allowlist is bounded to 4096 UTF-8 bytes and 32 unique IDs; each ID must be 1–128 ASCII letters, digits, underscore, dot, or hyphen. Invalid JSON, duplicate IDs/keys, wrong types, wildcard or malformed IDs produce a fixed configuration error without echoing the input. No `__builtins__`, `__import__`, or package view is intercepted, and non-target imports keep their original identity. Local imports inside an already-created handler are outside this slice. Async handlers selected by the existing dispatcher receive worker-thread awaitables; sync handlers and constructors retain native synchronous values. The wrappers preserve positional/keyword arguments, return values, `None`, and exceptions, including the existing caller-supplied chat owner ID. Repeated adaptation is idempotent. The adapter does not replace process-wide model attributes or `sys.modules`. The existing `utils/filter.py` task-local mode/reset remains, including reset after error or cancellation.

Focused validation after the opt-in correction: `validation/test_model_async_compat.py` covers bootstrap behavior, all selected plugin/model methods, off-loop calls and heartbeat, `None`/error propagation, direct/aliased bindings, exact dynamic imports, non-target import identity, unchanged builtins, repeated adaptation, default/unselected native `None`, selected awaited lookup using the loader's function ID, invalid and oversized allowlists, safe refusal text and no function deactivation, script path/hash/size/FIFO refusal, verified-byte use after path changes, CLI argument/status mapping, child config-import ordering, and singleton restoration. Existing `validation/test_filter_sdk_compat.py`, `validation/test_filter_priority.py`, and `validation/test_plugin_load_preservation.py` remain required regressions. `py_compile` uses `PYTHONPYCACHEPREFIX=/tmp/openatelier-atlas-compat-pycache`; `git diff --check` is required.

The initial committed draft automatically bridged Files/Chats for every async Filter, which could change legacy handlers relying on synchronous results. The added allowlist restores the legacy default and selects only exact loader function IDs. The earlier broad builtins import hook was also removed; module discovery uses already-loaded singleton/module identity without eager model imports. Test corrections recorded: the Users fixture needed its loaded module, a missing-importlib `None` identity check was fixed, and the first compile attempt needed a writable `PYTHONPYCACHEPREFIX`. The tests distinguish the intentionally native unselected `None` from selected awaited lookup.

No external bootstrap was executed. Tests use synthetic modules and a mocked process boundary; they do not establish actual application database behavior, installed-plugin compatibility, Python deployment compatibility, task cancellation semantics of every native SDK caller, or an isolation/security boundary for selected code. Unsupported import patterns include wildcard interception, copied/re-exported APIs outside the selected module bindings, dynamic aliases other than the exact observed module paths, and non-listed model methods. Existing asynchronous Filter dispatcher behavior is reused; broader plugin types and arbitrary imports remain unqualified.
