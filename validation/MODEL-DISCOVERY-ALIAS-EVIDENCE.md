# Authenticated callable-model discovery alias

The no-slash `GET /api/v1/models` route now decorates the existing `GET /api/models` callable-model aggregate. Both paths invoke the same handler and verified-user dependency; the workspace CRUD path `/api/v1/models/` remains separate. The optional `refresh` query parameter is typed as a boolean and intentionally does not create a new cache path: the legacy aggregate already resolves its callable inputs per request.

The 0.12.4 behavior-only probe covered 39 requests. Both paths returned JSON `{data: [...]}` with status 200 for authenticated roles, identical across omitted/false/true `refresh`; `refresh=invalid` returned422. Anonymous requests, including invalid query input, returned401. The owner saw all12 synthetic callable entries, the member saw only the named read-granted model and the public user-wildcard model, and an unrelated user saw only the public entry. Existing ACL filtering is reused. A group-wildcard fixture remained private upstream and is a known unsupported creation gap in the bounded grant parser.

The same current discovery fixture showed a shared preset to a member/unrelated user but both plain and SSE continuation calls returned400 `Model not found`. This is a failed continuation, not useful member access. It was not repaired in this route slice. The owner `portable_pipe` continuation is separately measured by the primary and is not claimed here. No additional provider, workspace redirect, cache design or model-storage behavior was added.

`python3 backend/open_webui/test/test_model_discovery_alias.py` executes the checked-in aggregate function extracted verbatim with injected synthetic dependencies. Its two named tests verify both source route decorators share the authenticated handler, boolean query annotation, and existing owner/member/unrelated/admin filtering of private, targeted-read and public models while excluding filter pipelines. `python3 backend/open_webui/test/test_explicit_access_grants.py` still passes eight current-rights form/helper tests. Source syntax compilation and `git diff --check` pass. These source tests do not run FastAPI request validation or establish HTTP status behavior; primary-owned pinned-runtime replay is required for those. No shared-preset inference, exact current response-metadata/history parity, cache behavior beyond this aggregate, or whole-version compatibility is claimed.
